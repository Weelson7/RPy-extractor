# 13 CLI

Area code `CLI`. Every `viwo` command once, with and without `--json`, plus `tools/version.py`.
Exit codes: 0 ok, 1 other failure, 2 invalid request / needs decision / needs key, 3 refused,
4 strict preflight failed (serve), 130 cancelled.

## SQC-CLI-01 (P0) `viwo extract --json` envelope and exit codes

Steps:
1. `viwo --json extract C:\sqc\zip-basic\game --workspace C:\sqc\_ws\cli1 --on-existing replace`
2. `viwo extract C:\nope --workspace C:\sqc\_ws\cli2; $LASTEXITCODE`
3. `viwo extract C:\sqc\zip-basic\game --workspace C:\sqc\zip-basic\game\x; $LASTEXITCODE`

Expected: 1: one JSON document on stdout: `ok: true`, `data.workspace`, `data.runs[0].plugin_id
= "generic"`, `data.files`, `warnings: []`; nothing on stderr (no progress lines in JSON mode).
2: `viwo: invalid_request: ...` on stderr, exit 2. 3: `viwo: refused: ...`, exit 3.

## SQC-CLI-11 (P0) Version tool: `tools/version.py`

Steps:
1. `python tools\version.py show`
2. `python tools\version.py verify`
3. `git tag --list v*` (latest tag) and compare with 1.
4. Make a trivial change (append a blank line to README.md), then `git commit -am test`.
5. `git checkout README.md`
6. `python tools\version.py bump tweak; python tools\version.py show; git checkout pyproject.toml viwo/__init__.py`

Expected: 1: `a.b.c`. 2: `version a.b.c ok (latest tag va.b.c)` when HEAD is tagged, exit 0
(after a bump without a tag it says ok too: the version is past the tag). 3: the latest tag equals
the version shown (every commit is tagged). 4: the pre-commit hook refuses: `version: a.b.c is not
past the latest tag va.b.c. Commit with: python tools/version.py commit -m "..."
[--feature|--major]`; no commit is created (`git log -1` unchanged). 6: `a.b.(c+1)` printed,
`viwo/__init__.py` and `pyproject.toml` both changed, then restored.
