# 17. Testing model

The suite uses the stdlib `unittest` (`python -m unittest discover -s tests -t .`); levels are
selected by environment variables, not markers. At 1.15.5: 552 tests, 13 skipped without the real
tools (about 10 minutes on Windows including the browser smoke).

## 17.1 Principles

1. **No real game data in the repository or in CI.** Every fixture is synthetic: generated by a
   builder at test time, tiny and deterministic. Freedoom (BSD) is downloaded by the CI real-tools
   job only.
2. **Fakes before real tools.** Every slot is tested with fake backends or fake tool scripts (a
   `.py` script plus a `.cmd` wrapper on Windows, `tests/test_godot.py` `fake_tools`). Real tools
   get smoke tests that skip with the tool named when it is absent.
3. **Every contract rule has a test** that would fail if the rule broke: single writer, reserved
   dot-folders, routing, failover, never-silent fallbacks, determinism, the warnings policy (D22),
   import direction, license isolation, declared network use.
4. **Properties over examples** where a rule is general (owner's rule): every command in exactly
   one arm, an arm word never changes a run, removed files named exactly, a warning whenever
   there is something to say.
5. **Safety is tested, not assumed:** malicious archives, path traversal, pickles, game-folder
   integrity.

## 17.2 Levels

| Level | What | Where | Runs |
|-------|------|-------|------|
| L0 static | `ruff format --check`, `ruff check`; LoC caps (`test_pipeline.py::test_loc_caps`); import direction, GPL/AGPL => subprocess, every backend declares `network` and `parses_untrusted_in_process`, `loc_caps.ini` schema (`test_l0_static.py`); distro drift and `viwo config check` (`test_config.py`); UI functional/style boundary (`test_ui_lint.py`); version scheme (`test_version.py`) | `tests/` | every run |
| L1 contract / unit | conformance kit over the built-ins, the example drop-in and `VIWO_PLUGIN_DIRS` (`test_conformance_kit.py`); OS layers (`test_os_layer.py`); selection, ini precedence, identify and carve rules, value types, journal | `tests/` | every run |
| L3 component | each plugin against synthetic fixtures with fake tools (`test_<engine>.py`, `test_formats.py`, `test_containers.py`, `test_slp.py`, `test_tpac_textures.py`, `test_redengine.py`) | `tests/` | every run |
| L4 matrix | selection over every plugin subset x policy, pairwise pipeline runs (`test_mixed.py`); every outcome kind through main and spare (`test_core_units.py::test_failover_outcomes`); binder states (`test_core_units.py`, `test_config.py`) | `tests/` | every run |
| L5 real tools | each real backend on its fixture through the runtime (`test_l5_tools.py`, `test_l5_data.py`, `test_thirdparty.py`); tools from `third_party/` or `VIWO_<ID>` overrides | `VIWO_L5=1` | CI real-tools job; locally on demand |
| L6 end to end | CLI (`test_cli.py`, `test_pipeline.py`: extract -> run record -> replay gives an identical workspace); HTTP (`test_server.py`, `test_api_routes.py`, `test_api_capture.py`, `test_settings.py`); browser smoke (`test_ui_smoke.py` + `tests/ui/smoke.mjs`: headless Edge/Chromium over the DevTools protocol, every view, zero console errors) | `tests/` | every run; the smoke skips without Chromium or Node, `VIWO_UI=0` disables it, `VIWO_UI_OUT` keeps screenshots |
| L7 manual and real games | the `sqc/` checklist; `tools/integration_games.py` over `Test-games/` (`sqc/games.md`); the games pass `tools/games_pass.ps1` with CTF flags (`sqc/ctf.json`); results as numbers and run records, never assets | owner, operator | before a release |

## 17.3 Safety catalogue

| Case | Expectation | Where |
|------|-------------|-------|
| zip/tar member with `../`, an absolute path, a device, or a link outside | rejected; nothing written outside the destination | `test_pipeline.py`, `test_formats.py`, `test_thirdparty.py` |
| symlink inside an archive | not followed: tar links filtered, zip entries written as plain files | `test_pipeline.py`, `test_conformance_kit.py` |
| RPA index with a `__reduce__` payload | no code runs; reported, the spare runs only as a subprocess | `test_renpy.py::test_malicious_index_never_runs` |
| `.rpyc` | never unpickled in process (unrpyc in a subprocess) | `test_renpy.py` |
| nesting depth bomb | stops at depth 10, reported | `test_pipeline.py` |
| decompression bomb | bounded per stream and per file (`viwo/core/carve/streams.py`), BSA inflation bounded, an RPA index inflates to at most 256 MiB | `test_carve.py`, `test_untrusted_input.py` |
| a plugin hook writing outside its staging | the conformance kit's sandbox check fails | `test_conformance_kit.py` |
| PREPARE on a folder without the marker | refused, nothing deleted | `test_game_integrity.py` |
| any extraction | game-folder hashes unchanged | plugin tests, `test_game_integrity.py` |
| a game file unreadable (antivirus) or removed mid-run | named in a warning, the run completes | `test_pipeline.py` |
| missing token, foreign Host, non-JSON body, oversized body, cross-origin `text/plain` POST | 403 / 415 / 413, no side effect | `test_server.py` |
| random bytes behind a format's magic, and valid archives randomly damaged, to every in-process reader | an Outcome (a named failure or what could be read), never an exception; nothing written outside the destination | `test_untrusted_input.py`, `test_redengine.py` |
| an empty or relative path in an API request | refused (`not_found` / `invalid_request`); the server's own folder is never read or written | `test_api_routes.py` |
| `/preview/` and `/api/*` traversal | 404 or an error | `test_server.py` |
| a journal left by a crashed capture session | restored before the next capture; a damaged line is skipped with a warning | `test_capture.py` |
| anti-cheat markers, an online title, a sensitive plugin | warnings and one confirmation, never a refusal (D22) | `test_capture.py::test_feature_switch_confirmation_and_warnings` |
| a patch whose original bytes differ, an AOB pattern found twice | refused before anything is written | `test_patchsets.py` |
| two mods writing one file differently, a requirement cycle | refused | `test_mods.py` |

## 17.4 Fixtures

Builders in `tests/helpers.py` (`make_zip`, `make_tar`, `make_rar`, `make_game`, `runtime(root,
ini_body)`) and in each plugin's test file (`make_rpa`, `make_pck`/`embed`, `make_pak`/`key_exe`,
`make_wad`, RGSSAD, MV encryption, XP3, asar, VPK, BSA/BA2, DRS, PFH, RDAR, TPAC, SLP). Unity uses
a stateful fake UnityPy and a fake AssetStudio. Fixture data is generated into a temporary
folder; no binary fixture is committed. `sqc/fixtures/build_fixtures.py` builds the fixtures of
the manual suite.

## 17.4b Terms-of-service-sensitive cases: independent operator

| Aspect | Rule |
|--------|------|
| Marking | `tos_sensitive=True` in the plugin manifest (Overwatch) |
| Project CI | fake-tool and synthetic tests only (`tests/test_overwatch.py`) |
| Operator receives | a pinned build, the plugin, the `sqc/` checks marked OPERATOR |
| Operator returns | run records, metrics and pass/fail per check, tool and game versions; never assets |
| Environment | the operator's own machine and licensed copy, offline where the game allows |
| Policy | none in the code (D22): the operator sees the reminder and carries the responsibility |

## 17.5 Tooling, CI and coverage

- Python 3.11 minimum; CI tests 3.11 and 3.13.
- CI (`.github/workflows/ci.yml`): `ubuntu-latest` and `windows-latest` x Python 3.11/3.13 for L0-L4
  and L6 under `coverage`, plus a real-tools job per OS (`viwo install --all`, then the suite with
  `VIWO_L5=1`). **Cost rule (owner):** CI runs only on a `vN.0.0` tag push or when the owner starts
  it by hand; no per-push run, no schedule. Everything runs locally before each commit
  (`tools/version.py commit`).
- Coverage floors (ratchet, `tools/coverage_check.py`, line coverage per layer): `viwo/contracts`
  90, `viwo/core` 86, `viwo/plugins` 80, `viwo/os` 60, `viwo` 75. The owner's target is 98 % line
  and 95 % branch **per file**; measured at 1.6.23: 98.6 % line, 95.3 % branch overall; 72 files are still under 98/95 on their own (open). Child
  processes (CLI runs, worker scripts) are measured: `[tool.coverage.run] patch = ["subprocess"]`
  in `pyproject.toml`, then `coverage combine`.

## 17.6 Definition of done (a feature or a release)

1. Format, lint, caps and the full suite green locally (`tools/version.py commit` runs them).
2. New safety rules have a test in 17.3.
3. Real-tool paths touched: L5 run with `VIWO_L5=1`; real-game paths: the games pass from a
   committed version (`docs/HANDOFF.md`).
4. Docs describe the new state; `docs/contract/CONFORMANCE.md` updated; `CHANGELOG.md` entry.
