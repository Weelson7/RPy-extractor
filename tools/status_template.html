What ViWo is

A local-first game reverse-engineering orchestrator: static extraction (engine plugins, container unpackers, carver, stream inflation, decoders, QuickBMS), static code analysis (Ghidra headless and the "Continue in Ghidra" handoff), runtime capture (RenderDoc, journaled), round trip into a verified patched copy, curation and sanitizer. Everything sits behind slots with main and spare backends, pinned third-party tools, run records, and a contract audited clause by clause. No boundaries or safeguards in the code: warnings plus one opt-in, a disclaimer, and the responsibility with the user.
